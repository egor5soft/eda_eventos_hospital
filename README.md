# Quality-control event log — exploratory data analysis

A standalone portfolio demonstration using entirely synthetic data. It illustrates relational joins, data quality checks, descriptive statistics, temporal coverage analysis and weekly event aggregation using Python.

## Run locally

```bash
python -m pip install -r requirements.txt
jupyter notebook quality_events_eda.ipynb
```

The notebook generates its own fictional data with a fixed random seed. No external dataset or institutional system is required. Outputs are intentionally not committed. This repository does not contain the original workplace code, data, internal schema, or findings. It does not demonstrate a trained forecasting model.

## Technologies
Python, pandas, NumPy, Matplotlib, Jupyter.
